# Книга Богов — проект сборки Android 17 APK

Автономное офлайн-приложение для чтения книги «Книга Богов» без доступа в Интернет, с точной пагинацией, правильным переносом слов между страницами и встроенным офлайн-генератором продолжения сюжета.

## Как собрать APK-файл на GitHub

1. Распакуйте данный ZIP-архив в отдельную папку.
2. Создайте новый репозиторий на GitHub (публичный или приватный).
3. Загрузите все файлы из распакованной папки (включая скрытую папку `.github/workflows/build-apk.yml`) в ветку `main`.
4. Откройте вкладку **Actions** в вашем репозитории на GitHub.
5. Запустите или дождитесь завершения рабочего процесса **Build Android 17 APK**.
6. Внизу страницы завершённой сборки в разделе **Artifacts** скачайте архив `kniga-bogov-android17-apk`, внутри которого находится готовый файл `app-debug.apk`.
7. Установите APK на устройство с Android 17 (поддерживается полноэкранный режим от края до края, жесты возврата и полностью автономная работа без сети).
